# Changelog

All notable changes to Void Aurora will be documented here.

## [1.1.0] — Indent & clarity update

### Changed
- Tree indent guides: stronger violet tint (`#7b68d445`) — folders and nesting depth now clearly visible in sidebar
- Active indent guide in editor: brighter accent (`#7b68d470`) — highlights the current scope at a glance
- Inactive indent guides: subtle but readable (`#7b68d428`)
- Fixed GitHub repository URL

### Recommended
Pair with **Material Icon Theme** (`pkief.material-icon-theme`) for folder/file icons and chevron arrows that match the aurora palette.

## [1.0.0] — Initial release

### Added
- Complete VS Code color theme with 660+ UI color tokens
- Semantic highlighting for TypeScript, JavaScript, Python, Rust, Go, HTML, CSS, SCSS, JSON, YAML, Markdown, Shell, GraphQL
- Full terminal ANSI color set tuned to the aurora palette
- Bracket pair colorization colors
- Git decoration colors
- Testing and debugging UI tokens
- Notebook / Jupyter support
- Status bar with violet accent
- Minimap theming
- Recommended settings in README
